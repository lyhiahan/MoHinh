================================================================================
          THÔNG TIN TRUY CẬP VÀ KHỞI CHẠY DASHBOARD HỌC MÁY
================================================================================

1. ĐƯỜNG DẪN DASHBOARD ONLINE (STREAMLIT COMMUNITY CLOUD):
--------------------------------------------------------------------------------
- Repository GitHub: https://github.com/lyhiahan/MoHinh
- Link Dashboard Online chính thức:
  https://mohinh-lyhiahan.streamlit.app
  (Sau khi bạn bấm Deploy trên Streamlit Cloud, dán chính xác URL của bạn vào đây nếu bạn đổi tên URL khác)


2. ĐƯỜNG DẪN TRUY CẬP TRÊN TRÌNH DUYỆT (LOCAL NỘI BỘ):
--------------------------------------------------------------------------------
Sau khi khởi động ứng dụng trên máy tính, truy cập:
http://localhost:8501


3. HƯỚNG DẪN KHỞI CHẠY TRÊN MÁY TÍNH (DÀNH CHO THẦY CÔ NẾU CHẤM OFFLINE):
--------------------------------------------------------------------------------
Bước 1: Mở Terminal (CMD / PowerShell) tại thư mục bài làm.
Bước 2: Chạy lệnh sau để khởi động Dashboard:

    streamlit run app.py

(Hệ thống sẽ tự động bật trình duyệt và hiển thị giao diện Dashboard)


4. TRƯỜNG HỢP MÁY CHƯA CÀI ĐẶT CÁC THƯ VIỆN CẦN THIẾT:
--------------------------------------------------------------------------------
Nếu máy báo thiếu thư viện, chạy lệnh sau:

    pip install -r requirements.txt
